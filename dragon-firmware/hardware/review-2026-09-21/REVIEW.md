# Revised Gerber review — 21 September 2026

Compared the new ZIP with the 20 September export. No input manufacturing files were changed.

Result: no electrical shorts or opens across 30 plated holes; all expected net memberships and divider/LED/touch/LDR topology remain correct. One fragile pad connection should be improved before manufacture.

## Required small routing correction

R4 (now named r4_100k), pin 2 / 5V, moved left by 1.27 mm. Its pad centre is (7.45007, -40.64000) mm. The bottom-layer 5V track remains centred at X=8.72008 mm and was widened to 0.762 mm. Pad radius is 0.9398 mm. Thus pad-to-track overlap in X is only 0.05079 mm. This is connected in ideal Gerber geometry, but is not a robust pad entry. Add a short bottom-layer 5V track from that existing trace to the pad centre (a 0.254 mm branch is sufficient for the divider; 0.762 mm also fits). See R4-connection.png. This is not a current-capacity issue: R4 carries only divider current, but loss of its supply connection would invalidate voltage sensing. Re-run DRC and export after the correction.

## Improvements verified

- Board edge expanded 1.27 mm. Board is now 27.94 x 25.40 mm (X x Y), one board, no panel or score lines.
- 5V U-track to adjacent edge now 1.56972 mm. Global minimum top copper to edge is 1.54 mm; bottom minimum 1.56995 mm. Prior close-edge issue is resolved.
- Both matrix paths remain 2.0 mm. ESP32 supply/ground trunk sections now 0.762 mm; remaining signals 0.254 mm.
- Minimum different-net copper gap approximately 0.219 mm. Minimum annular ring approximately 0.300 mm.
- All pad mask openings remain correct and do not expose other nets.
- Labels are on top silkscreen. Resistor labels show required values in the correct locations. The external row labels agree with its netlist, reading square-pad first from the top: IN5V, INGND, LED5V, LEDDIN, LEDGND, TOUCH3V3, TOUCHOUT, TOUCHGND, LDR3V3, LDRADC.
- Some capacitor text/body outlines still overlap solder-mask openings. Cosmetic only: the manufacturer may clip portions. Move/shrink these if clean text matters.

## Remaining limits

Values embedded in reference names (r1_330, r3_10k, r4_100k, r5_20k, 100nf3, 100nf4) agree with the intended circuit, but do not independently verify library/BOM values or components actually fitted. Native EasyEDA DRC and physical ESP32/socket fit remain unverified. Resistor pitch remains 10.3–10.5 mm; capacitors 5 mm; socket 2.54 mm. Off-board touch bypass and bulk capacitor are still required as previously described. Direct 3.3V matrix data and unisolated power sources retain the previous review limitations. Any panel must use these new board dimensions and be reviewed separately.
